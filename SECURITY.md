# Security policy

Hercules is a public Java functional programming library under development. No stable release has been published.

## Supported versions

Only the current development branch is reviewed on a best-effort basis. There is no supported released version or guaranteed response timeline.

## Reporting vulnerabilities

**Do not disclose vulnerabilities, credentials, working exploit details, or private data in public issues or pull requests.**

Use [GitHub security advisories](https://github.com/black-belt-badger/Hercules/security/advisories) and private vulnerability reporting where enabled. Provide a description, impact and a sanitized proof of concept. If private reporting is not enabled, contact repository maintainers privately before sharing a reproduction.

For ordinary bugs that do not involve vulnerabilities, use the public issue template.
